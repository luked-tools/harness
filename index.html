About Harness

A browser-based automotive diagnostic PCAP analyser for UDS, DoIP, TCP, DHCP, ARP, topology, identity, and software download evidence.

What Harness is for

Harness helps review classic Ethernet PCAP captures from automotive diagnostics. It groups protocol evidence into focused tools so you can inspect validation findings, UDS behaviour, DoIP discovery, node routing, TCP timing, address identity, and software download completeness.

Typical workflow

  • Load a classic Ethernet pcap.
  • Start in Validation Centre for the highest-signal findings.
  • Use Tool Info inside each tool for context-specific interpretation notes.
  • Jump into UDS, SWDL, Discovery, Node Map, Transport Timing, or Address Identity for supporting evidence.
